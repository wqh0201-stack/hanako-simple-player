## 0.8.0 · 2026-10-11

**极简重构落成。** 从上游 `openhanako-labs/openhanako-audio-player`（作者 Yuexiye）fork 后，
后端沿用、前端整个重写，按 Hana 的三种承载形态重新设计，砍掉 PV 舞台 / 黑胶唱盘 / 配色面板。

- 前端拆成 `index.html` + `app.js` + `style.css`（无构建），主题只跟随宿主 `hana.theme`。
- 多歌单：本地固定文件夹 + 自建导入列表，可切换 / 重命名 / 删除。
- 封面环境色背景（读封面右缘像素）+ 歌词两态薄纱。
- 指针涟漪（Canvas 2D 流光水面）。
- 跨源安全：`captureStream` 替代 `createMediaElementSource`（跨源会静音且不可逆）。
- 系统「正在播放」接线（macOS 控制中心 / 媒体键）。
- 红心 / 「我的喜欢」+「最近播放」固定列表。
- 搜索页（5 平台、搜歌曲/歌手、热门推荐）。
- 控制条重排（「静听 · 连续布局」）、音量单按钮 + 悬停上弹竖条、悬停抬升发光。

> 更早的 0.4.0–0.7.0 是**上游原版**的历史（tag 在本仓保留），与本仓极简重构线无关。
