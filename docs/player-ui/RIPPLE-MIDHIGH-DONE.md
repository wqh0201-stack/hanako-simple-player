### 1. 第六根滑杆「中高频灵敏度」（`midHighSens`）

- 新增参数，默认 `1.6`，范围 `1.0–3.0`，步长 `0.05`。`1.0` = 原有严格度。
- **一次松开中/高的四道门**（低频段不参与）：
  - 绝对门限 `ONSET_BASE_MID/HIGH ÷ (sens × mh)`
  - 归一化门限 `ONSET_NORM_MID/HIGH ÷ (sens × mh)`
  - 包络比：中频 `1 + 0.45/mh`、高频 `1 + 0.55/mh`
  - 通量比：中频 `1 + 0.6/mh`、高频 `1 + 0.7/mh`
- 中频四道门在 `mh=1` 时逐字节还原旧值（1.45 / 1.6）；高频为本次新增路径。默认 `1.6` 已实测定标（见下）。

### 2. 高频（踩镲）接入触发

- 新增 `highOn` 起音路径（高频段 2000–8000Hz），与低/中同一套「快慢包络 + 谱通量」判据。
- 产出 `kind: 'high'` 短波：**更轻更薄** —— 寿命：低 `1.24 + power×0.18`、中 `1.02 + power×0.18`、
  高 `0.82 + power×0.14`；注入半径：低 1.5 / 中 1.15 / 高 0.85；高频绘制时再乘 0.72 的淡出系数。
- 合并规则不变：同一瞬态只产一次波（低 > 中 > 高优先）。

### 3. 音频短波环数 2 → 4

- `draw()` 里 `layers` 统一为 4（原 `audio ? 2 : 4`）。
- **主次分明**：主环最亮，回声逐层变淡 `[1, .42, .24, .13]`（乘 0.52 基础 alpha）。
- **最终取值 4 层**：实拍对比后，4 层的「一圈一圈」层次感明显、且三层回声足够淡（0.42/0.24/0.13），
  与「中高频灵敏度」放开后的密度叠加不显吵。未退到 3 层。

## 四、新增断言（4 条）

1. `ripple-hihats-trigger-high-waves` — 踩镲（多音色 4/5.2/6.5/7.6kHz）出 high 类短波，且不混入 low
2. `ripple-midhigh-sens-loosens-detection` — 弱中频在 1.0 档不出波、3.0 档出波
3. `ripple-max-midhigh-keeps-steady-and-silence-quiet` — 最大灵敏度下稳态低音/静音仍零波
4. `ripple-audio-waves-draw-four-rings` — 音频短波实际画 4 层环（`rippleRingLayers` 探针数 ringPath 调用）

改写既有断言 2 条：`ripple-tool-five-sliders-and-reset` → `ripple-tool-six-sliders-and-reset`（5→6 杆）；
`ripple-tool-names-plain-language`（5→6 个中文 label，含「中高频灵敏度」）。

另修一条既有 flaky：`ripple-continuous-bass-field-bounded` 的判据换成
**绝对水平上限 + 峰值增长**（原“前后半均值/中位数比”既不稳又无区分力）。

实测对照（人为拆掉封顶/阻尼造“坏版本”）：

| 版本 | 场能量 max |
|---|---|
| 正常（封顶+阻尼都在） | 0.002 – 0.0033 |
| 拆掉封顶 | 0.0076 |
| 拆掉阻尼 | 0.0058 – 0.0095 |
| 两者都拆 | **3.8**（真无界） |

结论：均值/中位数“前后半比”对坏版本**无区分力**（坏版本 2s 内就饱和，比值仍≈1.0），
且受负载影响会假越线（实测 1.34）。而**绝对水平**区分得很干净，
故新判据 = `maxField < 0.005`（正常实测上限 0.0033 ×1.5 余量；最轻坏版本 0.0058 也被挡）
+ 后半峰值 ≤ 前半峰值×1.6（抓真正“越播越大”）。非产品缺陷，是判据选错。

新夹具：`hihats`（多音色高频包 4/5.2/6.5/7.6kHz）、`weak-mid`（双音色弱包 1/1.4kHz），
包长均为 0.15s。两处设计都针对整套负载下的不稳：① **多音色**而非单音 —— 单音能量集中在少数
FFT bin，窗口对齐一变就抖；② **包长 0.15s** 而非 0.07/0.08s —— 负载下 rAF 变慢、采样变疏时，
短包可能只被采到 1 个样本、包络爬升不够而假性漏触（实测整套里从 7 次起音掉到 1 次）。
定稿后 hihats 连测 6 轮均 7 次起音；weak-mid 严格档 0 / 调松档 6~7。
