## 时间与动画

- `liveProgress()` 与原有 `lyricTimeAt()`（词源偏移 + 用户已保存偏移）共同驱动浮点波峰。
  不使用原型固定 3 秒节拍，不另造播放时钟。暂停保留相位，继续由媒体时钟推进。
- Gaussian 波浪幅度上限15%，范围1句；相邻句约放大9%，两句外约2%。
  文字 span 用 transform，整行字重、字号和行几何保持稳定；为峰值预留水平及垂直余量。
  尺寸变化时批量测量文字高度、缓存行中心，播放每帧只更新附近行的呈现和滚动。
- 时间轴与行中心都用单调三次插值，换句处位置与速度连续。
  原生 scrollTop 的像素舍入由内容层亚像素位移补偿。
- 实际 `.is-current` / `aria-current` 仍按歌词时间戳标记，视觉波峰可提前靠向下一句。
  相同时间戳保留双语行，以最后一行为语义当前行，不制造零时长插值段。
- 大于 12 秒的间奏先停留，下一句前 6 秒开始流入；首句前、末句后不空跑动画。
- 手动浏览暂停自动滚动，3 秒后用 0.5 秒过渡回归；调整尺寸时保留浏览锚点。
  点击跳句、长按拖动校准、校准微调/保存/换歌词继续使用原有控制流。
  校准时停阅读波浪，共用稳定行几何与原有草稿时间插值。
- 暂停、隐藏、离屏、队列/搜索遮挡、无词、长间奏停留及末句后停止 rAF。
  reduced-motion 与截图模式只做静态行级呈现。
