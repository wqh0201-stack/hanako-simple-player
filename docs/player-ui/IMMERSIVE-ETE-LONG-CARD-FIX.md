继续共用一份 `#playerBackdrop`。长卡将其放进 `#scene`，背景通过现有容器自动裁切；宽窗与矮卡将其放回 `#player`。封面尺寸继续按背景容器计算，不复制图片，也不新增依赖固定高度的裁切层。
