## 1. 主问题：mask-image 有值，不等于遮罩能连续插值

位置：`ui/app.js:8500–8513`，`stripLyricExitFrames()`。

当前给 WAAPI 三个 `maskImage: linear-gradient(...)` 关键帧，分别为边缘 0%、52%、100%。本机 Chrome/155.0.8059.84 对这些渐变图像做离散切换，而不是连续推进渐变停靠点。

从生产源码原样提取函数，用实际歌词 CSS、22px 十字单行，暂停动画并设置 101 个进度点：

```json
{
  "visibleGlyphs": 10,
  "particles": 140,
  "uniqueMaskStates": 3,
  "changes": [
    {"progress": 0.00, "transparentStop": "16.19%", "opaqueStop": "20.59%"},
    {"progress": 0.28, "transparentStop": "49.06%", "opaqueStop": "53.46%"},
    {"progress": 0.78, "transparentStop": "79.41%", "opaqueStop": "83.81%"}
  ],
  "endOpacity": 0.9
}
```

含义：约 28% 时从初态直接跳到中段，约 78% 时再跳到末段，中间没有逐字扫过去。粒子却按 `birth = 24 + sweep * dissolveMs * 0.95 + jitter` 分批出生，两者不同步，完全可能出现“只见半句动了、另一半突然不见”的观感。**本轮确定的是这一缺陷，不把用户真实现场的所有现象都归结为唯一原因。**

同样给参考稿 Scene.update() 101 个时间点：

```json
{
  "uniqueMaskStates": 77,
  "endOpacity": 0,
  "sweepCompleteAtMs": 380,
  "durationMs": 500,
  "tailMs": 1870
}
```

参考稿在前 76% 时段逐帧改遮罩坐标；后24%不再推进。所以是77种状态，不是101种。它不依赖浏览器替渐变字符串插值。

**对前一交接的修正**：把 `webkitMaskImage` 改成 `maskImage` 解决了“属性无效”，但只看到一个中途 gradient 或半句截图，不能证明连续动画已实现。

## 3. 与目标差很远的原因不只是强度

位置：`createStripLyricDust()` / `paintStripLyricDust()`，`ui/app.js:8372–8484`。

| 项 | 参考稿 | 当前实现 |
|---|---|---|
| 消散边 | 逐帧更新真实字形范围的前沿 | 三档跳变 |
| 普通粒子材质 | 白亮芯、彩色径向柔光sprite | 直接画纯色实心圆，普通半径封顶0.85px |
| 光层次 | 细点、星芒、星云、少量速度尾迹 | 小圆点及简单十字线，无径向柔光sprite、无速度尾迹 |
| 运动 | 数十到百余px/s的分散、摆动、弯曲 | 强度0.5再次缩小速度，几px/s到十余px/s |
| 余辉 | 慢场景1870ms，夜场2150ms，单粒独立寿命 | 常速约480ms，慢速约780ms，统一tail控制 |
| 文字完成态 | dissolve结束后旧句 opacity=0，粒子继续 | 末关键帧 opacity=0.9，副本留到整个motion清理 |

“强度50%”只是两份实现各自的参数标签，不能当视觉等价证据。参考默认25%，本次参考十字采样总数随机约496；再按 visibility 阈值筛选。当前140颗没有同款阈值筛选，不能只比总数就断言当前必然粒子更少。

当前末帧只扫到字形右界、羽化带仍跨过尾字，加上opacity=0.9，存在尾字柔边残留到余辉清理的风险。参考稿明确把文字归零、保留独立粒子。

## 4. 建议的最小修正范围（本轮未实施）

1. 让遮罩与粒子出生共用一个连续前沿/时钟；已有转场rAF可逐帧设置遮罩，不另建常驻循环。也可用经实际验证可插值的数值属性，不能继续假定maskImage字符串会插值。
2. 消散结束明确隐藏旧句，只让粒子独立留尾；新句按原歌词时钟原位淡入。
3. 按参考恢复光芯、径向柔光、少量星芒/尾迹和运动层次；颜色继续跟宿主/进度星光，画布保持条内，不照搬fixed全屏画布。
4. 预算整句均摊，不顺序裁尾；保留多行/省略可见字形边界。
5. 验收优先拍“首字、中字、末字”的连续转场，记录连续遮罩状态和每个可见字的实际粒子覆盖；一次联合看快/慢、两行、窄条与中断，不跑无关全量。
